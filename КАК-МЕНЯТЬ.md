# Как устроен сайт и как его быстро менять

## Что где лежит

```
elienglish/
├─ site/                    ← это и есть сайт, именно эта папка уйдёт в интернет
│  ├─ index.html            ← английская страница: все тексты и блоки (главный файл)
│  ├─ pl/index.html         ← польская страница, СОБИРАЕТСЯ АВТОМАТИЧЕСКИ, руками не править
│  ├─ assets/css/style.css  ← внешний вид: цвета, шрифты, отступы
│  ├─ assets/js/main.js     ← цены, пакеты, формы, меню
│  ├─ assets/img/           ← фото преподавателей и стоковые фото
│  ├─ send.php, config.php  ← отправка заявок боту в Telegram (config.php не в git)
│  ├─ og-en.jpg, og-pl.jpg  ← картинки, которые видно, когда ссылкой делятся в мессенджерах
│  ├─ robots.txt, 404.html  ← для поисковиков и для несуществующих адресов
│  ├─ .htaccess             ← настройки хостинга: HTTPS, без www, сжатие, кэш
│  └─ favicon-*.png         ← иконка вкладки (белая буква e)
├─ tools/
│  ├─ build.mjs             ← сборка: польская страница, разметка для поисковиков
│  ├─ serve.mjs             ← просмотр сайта у себя
│  └─ shot.mjs, render.mjs  ← мои инструменты для проверки
├─ image/                   ← исходники фото и ваши примеры (не в git)
└─ КАК-МЕНЯТЬ.md            ← эта памятка
```

## Главное правило

Английская и польская страницы почти одинаковые, поэтому правится одна, `site/index.html`. После любой правки в ней запустите сборку, и польская страница обновится сама:

```
node tools/build.mjs
```

То, что отличается у польской страницы (слоган, заголовок вкладки, описание для поисковиков, фото преподавателя), лежит в начале файла `tools/build.mjs`, в блоке `const PL`.

## Как посмотреть сайт у себя

1. Откройте терминал в папке `elienglish` и запустите `node tools/serve.mjs`.
2. Откройте http://localhost:5175 (английская) и http://localhost:5175/pl/ (польская).
3. После изменений: `node tools/build.mjs`, затем обновите страницу (Ctrl+F5).

## Чем открывать файлы

Удобнее всего бесплатный редактор VS Code: «File → Open Folder», выбрать папку `elienglish`.

- **Ctrl+P**: открыть файл по названию (набрать `main.js`).
- **Ctrl+F**: найти текст в открытом файле.
- **Ctrl+Shift+F**: найти текст во всех файлах сразу.
- **Ctrl+Z**: отменить, если что-то сломалось.

Главный приём: **ищите на сайте фразу, которую хотите поменять, через Ctrl+Shift+F.** Если нашлась в `site/pl/index.html`, правьте не там, а в `site/index.html` или в блоке `PL` в `tools/build.mjs`.

## Где что менять

| Что хотите поменять | Файл | Что искать |
|---|---|---|
| Любой общий текст на странице | `site/index.html` | саму фразу |
| Слоган, заголовок вкладки, описание для поисковиков (английская) | `site/index.html` | `<title>`, `description`, `data-i18n-html="title"` |
| То же для польской | `tools/build.mjs` | блок `const PL` |
| Цены за урок | `site/assets/js/main.js` | `var BASE` (онлайн, 60 и 90 минут, для каждого языка) |
| Доплата за выезд | `site/assets/js/main.js` | `OFFLINE_EXTRA` |
| Пакеты, скидки, подзаголовки, сроки, бонусы | `site/assets/js/main.js` | `var PACKS` |
| Цвета | `site/assets/css/style.css` | `:root` (общие и английский), `html[data-lang="pl"]` (польский) |
| Шрифты | `site/index.html` и `style.css` | `fonts.googleapis` и `--font` |
| Телефон или Telegram | все файлы | `79777480796` или `Eligolc` (встречаются несколько раз, меняйте все) |
| Вопросы и ответы | `site/index.html` | `faq__item` |
| Фото | `site/assets/img/` | `teacher-en`, `teacher-pl`, `adults`, `kids` |
| Адрес сайта (после выкладки) | `tools/build.mjs` | `const SITE_URL` |

Блоки в `index.html` подписаны комментариями: `<!-- Первый экран -->`, `<!-- Пробный урок -->`, `<!-- Подход и формат -->`, `<!-- Для кого -->`, `<!-- Цены -->`, `<!-- Вопросы -->`, `<!-- Запись -->`, `<!-- Контакты -->`. Места между метками `<!-- seo:start -->`, `<!-- schema:start -->` и подобными заполняет сборка, их не трогайте.

## Примеры

**Поменять цену английского онлайн за 60 минут на 1 600 ₽.** В `main.js` найдите строку:

```
var BASE = { en: { 60: 1500, 90: 2000 }, pl: { 60: 2000, 90: 2500 } };
```

замените `1500` на `1600` и запустите `node tools/build.mjs`. Пакеты, «Один урок», сообщение в Telegram и цены в разметке для поисковиков пересчитаются сами.

**Поменять скидку пакета 10 уроков на 7%.** В `PACKS` найдите `{ n: 10, off: 5, ...` и замените `5` на `7`.

**Поменять фиолетовый.** В `style.css` в блоке `:root` замените `--accent: #4B3BC9;` на свой цвет. `--accent-ink` это тот же цвет чуть темнее (для наведения на кнопку).

**Добавить вопрос.** В `index.html` скопируйте целиком один блок `<div class="faq__item"> ... </div>`, вставьте ниже, поменяйте текст и номера `faq-6` на `faq-7` (в трёх местах внутри блока), затем `node tools/build.mjs`. Вопрос появится на обеих страницах и в разметке для поисковиков.

## Когда сайт будет в интернете

1. Впишите адрес в `tools/build.mjs`: `const SITE_URL = 'https://ваш-домен.ru';`
2. Запустите `node tools/build.mjs`. Появятся canonical, картинки для мессенджеров и `sitemap.xml`.
3. Добавьте сайт в Яндекс Вебмастер и Google Search Console, укажите там `https://ваш-домен.ru/sitemap.xml`.

## Git: сохранить правку

```
git add -A
git commit -m "Что поменяли, своими словами"
git push
```

## Чтобы ничего не сломать

- Меняйте только текст между тегами `>текст<` и цифры. Не удаляйте кавычки, `<`, `>`, `;`, `{ }`.
- `&nbsp;` в текстах это неразрывный пробел (чтобы «в», «с», «к» не отрывались от слова). Можно оставлять.
- Если что-то сломалось: `git checkout -- site` вернёт сайт к последнему сохранению в git.
- Фото лучше не подменять напрямую: присылайте мне, я сожму их в лёгкий формат и вырежу фон.

## Самый быстрый способ

Напишите мне одной фразой, что поменять, например: «поменяй цену польского на 2 200» или «добавь вопрос про оплату». Я сам найду место, поменяю, соберу, проверю на телефоне и компьютере и сохраню в git.
